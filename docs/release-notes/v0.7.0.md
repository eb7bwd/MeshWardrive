## Novedades

**Mapa de cobertura (nuevo)**
- Pantalla de consulta en **Datos → Análisis → Mapa de cobertura**: mapa de calor sin puntos, sin el ruido de la medición.
- Estimación de cobertura en las zonas aún sin medir, siempre rayada para no confundirla con datos reales.
- Relieve opcional: se descarga la elevación de la zona visible y la estimación tiene en cuenta si una loma tapa la vista a los nodos que te oyeron. Después funciona sin conexión.
- Ficha de cada celda: medida o estimada, SNR, fechas, antigüedad de los datos, fiabilidad, altitud y qué nodos te oyeron allí.

**Condiciones y criterio de valoración**
- Al empezar, una hoja rápida con cómo llevas el nodo (bolsillo, coche, techo…), antena y potencia. Calcula la dificultad de la salida y se guarda con el wardrive (también en el `.mwd`).
- Criterio ponderado (por defecto): un fallo con el nodo en el bolsillo ya no marca la zona como «sin cobertura»; queda «sin confirmar». Manda la última salida fiable. El criterio clásico sigue disponible.
- Indicación de cobertura nueva (▲) y perdida (▼) sin borrar el historial.

**Medición**
- Ping según la velocidad (SmartBeaconing, como en APRSdroid). Desactivado por defecto.
- Ping inteligente mejorado: solo cuentan las mediciones con respuesta, límite de intentos fallidos por celda y salida, y distancia mínima entre mediciones.
- Espera de respuesta por defecto de 30 s. Si la respuesta llega cuando ya te has movido más de 75 m, el acierto se coloca donde llegó.
- Los pings que tu propio nodo no llega a emitir (por ejemplo por el ciclo de trabajo) se marcan como «no enviado» y no cuentan como falta de cobertura. Con el ciclo de trabajo agotado, los pings se pausan 5 minutos.
- Aviso si el nodo tiene rol de repetidor; se recomienda CLIENT_MUTE.
- GPS del nodo más fiable: edad calculada con la hora del fix, precisión del canal (precision bits) y diagnóstico en el Registro.

**Datos y mapa**
- Borrar mediciones concretas desde el mapa: un ping, una celda o una zona, con deshacer.
- Filtro de fechas (hasta una fecha o un intervalo) y botón «Solo el último».
- Toca la leyenda para ver qué significa cada color.
- Modo nocturno (Ajustes → Mapa → Tema).

**Ayuda**
- Cada ajuste numérico lleva una línea que explica para qué sirve.
- Tutorial, «Cómo se calcula cada valor» y README actualizados.

La base de datos se actualiza sola al abrir la app; no se pierde nada.

## What's new

**Coverage map (new)**
- Lookup screen under **Data → Analysis → Coverage map**: heat map without points, free of measuring clutter.
- Coverage estimate for areas not measured yet, always hatched so it is never mistaken for real data.
- Optional relief: the terrain elevation of the visible area is downloaded and the estimate checks whether a hill blocks the view to the nodes that heard you. It then works offline.
- Sheet for each cell: measured or estimated, SNR, dates, data age, reliability, altitude and which nodes heard you there.

**Conditions and valuation criterion**
- When starting, a quick sheet with how you carry the node (pocket, car, roof…), antenna and power. It works out the outing's difficulty and is stored with the wardrive (also in the `.mwd`).
- Weighted criterion (default): a failure with the node in your pocket no longer marks the area as «no coverage»; it stays «unconfirmed». The latest reliable outing wins. The classic criterion is still available.
- New coverage (▲) and lost coverage (▼) are marked without deleting the history.

**Measuring**
- Ping by speed (SmartBeaconing, as in APRSdroid). Off by default.
- Better smart ping: only measurements with a reply count, a limit of failed attempts per cell and outing, and a minimum distance between measurements.
- Default reply wait of 30 s. If the reply arrives when you have moved more than 75 m, the success is placed where it arrived.
- Pings your own node fails to transmit (for example because of the duty cycle) are marked «not sent» and do not count as missing coverage. With the duty cycle used up, pings pause for 5 minutes.
- Warning if the node has a repeater role; CLIENT_MUTE is recommended.
- More reliable node GPS: age taken from the fix time, channel precision (precision bits) and diagnostics in the Log.

**Data and map**
- Delete specific measurements from the map: a ping, a cell or a zone, with undo.
- Date filter (up to a date or an interval) and an «Only the latest» button.
- Tap the legend to see what each colour means.
- Night mode (Settings → Map → Theme).

**Help**
- Every numeric setting has a line explaining what it is for.
- Tutorial, «How each value is calculated» and README updated.

The database upgrades itself when the app opens; nothing is lost.
